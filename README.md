# Payel Portfolio

A single-page personal portfolio website built with HTML and CSS. It presents an introduction, skills, resume summary, work gallery, and contact area in a clean, responsive-style layout.

## Preview

Open `index.html` in a web browser to view the site.

## Features

- Header navigation and hero section
- About-me profile and contact details
- Technical-skills cards
- Education and experience summary
- Project image gallery
- Contact form layout and social-media icons

## Built with

- HTML5
- CSS3
- [Open Sans](https://fonts.google.com/specimen/Open+Sans) via Google Fonts
- [Font Awesome](https://fontawesome.com/) for button icons

## Project structure

```text
portfolio1/
|-- index.html          # Page markup
|-- styles/
|   `-- style.css       # Site styles
`-- images/             # Profile, background, gallery, and icon assets
```

## Run locally

This is a static website, so no installation or build step is required.

1. Clone or download this repository.
2. Open `index.html` in your preferred browser.

For live reload while editing, open the project with a local development server such as VS Code's Live Server extension.

## Customization

Update `index.html` to replace the sample name, biography, resume entries, contact information, and gallery images. Adjust colors, spacing, and layout rules in `styles/style.css`.

> The navigation links, download button, contact button, and form are currently visual elements; connect them to real pages, files, or a form service before publishing.
